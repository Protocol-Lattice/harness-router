02 / The decision stack

The right depth
for the next step.

Reuse a known choice. Ask Jev when tools overlap. Look ahead when downstream outcomes matter.

Inside the router ↗
↗
01CacheReuse+

A compatible state can reuse a previous decision. The hook cache includes the goal, observation, last action, and tool catalog.

same state→cached choice
02JevChoose+

Resolve a closed choice among available tools through OpenRouter. Large registries can be narrowed by category before selecting a tool.

available tools→next tool
03MCTSLook ahead+

Search a supplied, side-effect-free state graph when the first choice depends on later outcomes. Simulate the possibilities, then return the first action.

simulated paths→first action

MCTS is optional and needs a simulator. A fallback hands the choice back to the planner.

04 / Get started

Python 3.11+ · OpenRouter API key

Make the connection.

Install the router, add your key, and connect the harness you use.

Your harness

Project hooks connect routing to the agent lifecycle. For explicit calls, use MCP or the Python API ↗.

01 Install the router

Terminal
uv / harness-router
uv tool install --force --with 'mcp>=2,<3' \
  'git+https://github.com/Protocol-Lattice/harness-router.git@main'

02 Set your provider key

Environment
export OPENROUTER_API_KEY="your-key"

Make the key available to the harness process before starting a session.

03 Connect Codex

Git project root
Project hook installer
curl -fsSL https://raw.githubusercontent.com/Protocol-Lattice/harness-router/main/scripts/install_hook.py \
  | python3 - --provider codex
Finish installing the adapters +

The current Codex and Claude Code installer also needs these two adapter files. Run this after installing the hook.

Prompt and stop adapters
for hook in pre_decision stop; do
  curl -fsSL "https://raw.githubusercontent.com/Protocol-Lattice/harness-router/main/.codex/hooks/${hook}.py" \
    -o ".codex/hooks/${hook}.py"
done

Start a fresh Codex session

The startup hook discovers tools. Prompt and result callbacks then prepare the next choice for local validation.

Integration guide ↗

The installer merges settings and backs up changed files. Add .harness-router/ to your project's .gitignore for shared session state.
